Entry Paths

Three clean ways into the system.

Path 01Identity First
Start with who
The user enters through a person, performer, or subject and then branches into appearances, related shows, and attached media.
Path 02Event First
Start with the show or event
The user remembers the night first, then browses the people, the chronology, and the media extracted from that event shell.
Path 03Signal First
Start with a search pulse
A future command-style search can let the browser suggest routes instead of only matching records.
Suggested command layer: scope:core medium:photo query:"first live collection"
