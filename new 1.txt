Instagram Plan

Connection setup
Add an Instagram Publishing block to the admin shell beside or under Facebook.
Create backend auth flow for Instagram through Meta.
Require an Instagram professional account connected to a Facebook Page.
Store:
Instagram account ID
linked Facebook Page ID
access token
token expiry / refresh info
Add Connect Instagram, Check Connection, and Disconnect Instagram.

Backend basics
Add backend routes for:
/admin/instagram/status
/admin/instagram/connect/start
/admin/instagram/connect/callback
/admin/instagram/disconnect
/admin/instagram/preview
/admin/instagram/publish
/admin/instagram/history
Reuse the same admin-token protection pattern as Facebook.

Frontend composer wiring
Reuse the current Photo Post picker and selected-photo flow.
Add platform-aware mode so the same selected archive item can target Instagram.
Keep first version simple:
Photo Post only
no Normal Post
no link field in final Instagram caption output
Reuse:
title toggle
hashtags toggle
caption box
Hide unsupported fields when Instagram is selected.

Single-image first pass
Start with one selected photo only.
Backend publish flow:
create Instagram media container
publish container
Preview should show:
target IG account
image preview
final caption
Confirm successful feed post end-to-end before touching carousel.

Multi-photo carousel second
After single-image works, add multi-photo publish.
Backend flow:
create child media containers
create carousel container
publish carousel
Use the current multi-select picker UI as the source.
Keep album-style branching out of scope for Instagram first pass.

Caption rules
Build Instagram-specific final message assembly:
optional title
caption
optional hashtags
Do not append site URL by default unless you explicitly want it.
Keep formatting cleaner than Facebook because IG is caption-first.

Media requirements
Make sure selected images use full-resolution public URLs.
Verify Meta can fetch the image URLs from the backend/source.
Add clear error handling for:
invalid image URL
unsupported media
container creation failure
publish failure

History and status
Add Instagram publish history panel like Facebook.
Log:
entity label
selected photo count
publish status
Instagram media/container IDs
error message if failed
Show friendly status copy in the admin shell.

Verification checklist
Connect account successfully
Fetch Instagram account status successfully
Publish one single-image post
Confirm caption formatting
Confirm image is full-res
Publish one carousel
Confirm history logging
Confirm disconnect/reconnect works

Nice-to-have after core works
Instagram-specific mention/handle drafting
scheduled posting
reels/video path
platform-specific caption presets
cross-post workflow from one selected archive item


Best build order
Instagram auth + status
Single-image publish
Preview + history
Carousel publish
polish/error handling

Important constraint
Instagram should be treated as its own backend publishing system, not a copy of Facebook with renamed labels. The picker/frontend can be reused heavily, but the actual publish logic should be platform-specific.
